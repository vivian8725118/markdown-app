常见问题

安装、激活与隐私

macOS 提示「无法打开，因为无法验证开发者」？
官网直装的 DMG 在未完成 Apple 公证前会出现此提示。请右键应用 →「打开」确认一次； 或在「系统设置 → 隐私与安全性」中允许。我们后续会为安装包做公证以简化流程。
Windows 安装被 SmartScreen 拦截？
新应用常见提示，选择「更多信息」→「仍要运行」即可。也可使用 zip 免安装包解压运行。
必须用支付宝吗？
国内用户以支付宝为主即可（个人收款码、商家码或第三方店铺均可）。 海外用户日后可能增加 PayPal / 信用卡渠道；应用本身不绑支付方式，只验证激活码。
专业版如何激活？
购买成功后你会收到一封邮件，内含激活码。打开 Markdown → 设置（⌘ ,）→ 输入激活码。 激活状态保存在本机，可离线使用。
会上传我的文档吗？
不会。编辑与预览均在本地完成；除非你自己导出或分享文件，内容不会离开电脑。
